# 远见 · 出海情报工作台

以飞书 Base 为正式数据源，将公开业务信号推进为可核实、可跟进的行动。

**当前交付：本机运行的完整应用 + 私有 GitHub 源码仓库。** GitHub 保存代码，不承载客户数据；本项目尚未部署为远程在线服务。

## 工作路径

公开信源 → 采集收件箱 → 来源核实 / AI 研判 → 关联现有公司与关键人 → 跟进任务 → 客户反馈。

- 情报精选：搜索、类别/可信度/客户筛选、按日期查看、收藏、CSV 导出。
- 情报收集：关键词（Google News RSS，默认近 30 天）、RSS / Atom、网页正文或手动摘录。相同链接及跟踪参数变体自动跳过。
- 待核实收件箱：本地保存，可修改原始链接和摘录；相似英文标题提示人工归组。
- AI 研判：选中单条后发起中文摘要、来源说法/证据、业务相关度、推荐理由、候选公司、销售假设与核实动作。结果保持待核实。
- 转化队列：查看待关联情报和候选行动；创建、编辑飞书 Activities 任务，通过摘要中的情报 ID 回溯来源。
- 客户与联系人：显示现有岗位、LinkedIn、可信度、在职风险与公司关联，支持核对后增量新增或编辑。
- 话术与跟进：读取飞书 Playbook 模板，复制后由使用者按实际沟通背景调整。
- 字段写入：展示目标表、变化前后值，明确确认后写入；读取当前值防止覆盖他人更新，写后逐字段读回，并重新同步七张表。

## 本机启动

需要 Node.js 20 或更新版本，以及已安装并完成用户身份授权的 `lark-cli`。工作台复用本机飞书登录，仓库不包含飞书凭据。不依赖第三方 npm 包。

```sh
npm start
```

打开 <http://127.0.0.1:4317>，进入「连接设置」粘贴飞书 Base 链接，再点击「同步七张表」。首次同步会自动识别以下英文前缀，表名可带中文后缀：

| 工作台 | 飞书表名前缀 |
| --- | --- |
| 客户 | Accounts |
| 联系人 | Contacts |
| 跟进任务 | Activities |
| 商机（只读） | Opportunities |
| 情报 | Intelligence |
| 话术库（只读） | Playbook |
| 漏斗口径（只读） | Funnel |

也可以在首次运行前设置 `FEISHU_BASE_URL` 环境变量，并运行 `npm run sync`。应用不自动加载 `.env` 文件，使用系统环境变量或设置页即可。`PORT` 可覆盖默认端口。

现有工作目录已经连接 Base 时，不能直接切换另一个 Base，避免混合业务资料；其他 Base 请使用独立的项目副本与数据目录。

## 大模型 API

在「连接设置 → 大模型 API」填写：

1. 完整 Chat Completions 接口地址，含 `/chat/completions` 路径。
2. 服务商提供的准确模型 ID。
3. API Key。已保存后留空会保留原密钥；可单独清除。

兼容接受 `model`、`messages`、`stream:false`、`max_tokens` 和 `response_format:{type:"json_object"}` 的接口。以服务商当前文档为准，例如 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。模型需要支持 JSON 输出。

每次点击「开始 AI 研判」才请求一次模型，由用户自己的 API 账户计费。发送范围明确展示在分析预览中：当前文章标题、公开链接、最多 18,000 字来源摘录、客户公司名称及记录编号。**不发送联系人邮箱/电话、客户备注或商机金额。** 模型输出仅接收已有公司的 ID、既有分类/产品枚举；事实证据须逐字存在于提交的摘录，缺乏证据的事实丢弃。摘要与判断仍需人工阅读原文核实。

密钥保存到本机 `.data/model.json`，权限 600；接口不会把密钥回传浏览器，Git 排除整个 `.data/`。

## 数据与运行边界

- 飞书是正式业务记录的唯一底座；本机快照和采集草稿在 `.data/`，请自行备份本机目录。删除项目副本会丢失尚未写入飞书的草稿。
- 同步七张表全部成功才替换快照；分页不完整、重复 ID 或读取期间版本变动时保留旧快照。
- 新增前重新读取对应表去重：创建公司按规范化名称、联系人按姓名+公司、情报按规范化来源链接阻止明显重复。跨语言别名、集团/产品关系与不同 URL 的转载仍需人工判断。
- 编辑采用读前比较，并非飞书事务式条件更新；另一个人在比较与写入间极短窗口内修改同一字段，仍有竞争风险；多个独立工作台同时创建相同对象也需要人工核查。
- 同一请求编号保存回执，结果不确定时阻止重复创建。飞书写入成功但读回失败时，会提示先同步核对，不能换请求编号直接重试。
- 商机与采购意向、已触达、已建任务分开统计。任务不会自动勾选「是否已用于建联」，不会自动新增商机或估算预算。
- Google News / RSS 摘要可能仅含标题；建议补充原文摘录后再分析。Google 聚合跳转链接并不等于已核实原始报道。
- 采集仅访问公开 HTTP(S) 来源，限制体积、时间、重定向并阻止内网地址。网页只提取当前页面，不绕过登录、反爬或付费墙。JSON 列表、X、公众号采集暂未接入。
- 仅绑定本机回环地址，带 Host / Origin 检查与写请求令牌。**不能直接改成对公网开放**；远程部署需要另外配置登录、权限、持久存储、HTTPS 和运行环境中的飞书授权。
- 当前提供按需采集、单条研判、相似标题提示。持续后台采集、向量/模型事件聚类、双模型评分、日报与成本仪表盘尚未实现。

## 参考与取舍

信息收集借鉴 [AIHOT](https://github.com/KKKKhazix/AIHOT) 公开介绍的信源 → 去重 → 筛选 → 摘要 → 事件组织思路；使用自己的品牌、行业标准与独立实现，不包含其品牌资产或运营数据。Sales Buddy 仅作为客户卡片与用户确认交互的轻量参考，数据结构始终以实际 Base 为准。

## 检查

```sh
npm run check
npm test
```

测试使用临时模拟表，覆盖完整同步、旧快照保留、来源去重、公司/联系人防重复、字段允许列表、并发修改保护、写后读回、保存回执、模型证据筛选、模型密钥不回传和本机请求防护。运行测试不会向真实 Base 写入测试记录。
